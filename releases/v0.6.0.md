# SeekDeck v0.6.0

スマートフォンを横向きにして使う、2デッキの演奏画面へ更新しました。

- 左右のターンテーブルと中央ミキサーを同時表示。CUE・再生・SYNC・音量・クロスフェーダーをスクロールせず操作できます。
- A/B・C/Dの組切り替え、各デッキのJOG / PADS / FX・TEMPO、中央EQ表示に対応。
- デッキのフォルダボタンから対象デッキを指定して選曲し、ロード後は演奏画面へ戻ります。
- マスター音量・録音・波形配色・コントローラーを設定画面から操作できます。
- 横画面・縦画面・PC表示の切り替え中も再生を継続。デッキ選択と操作パネルを保存し、既存セッションも移行します。
- 縦画面は補助UIとして残し、横向きでの演奏を案内します。

Chromiumのタッチ環境で小型・標準・大型の横画面、デッキ操作、選曲、回転中の再生、状態復元を検証します。GitHub Pages・デスクトップ・ファイル交換の既存チェックも継続しています。iPhone/Android実機による音声・ハードウェア検証は未実施です。

参考: [djay for iOS のターンテーブルとミキサー構成](https://www.algoriddim.com/djay-ios)。音声エンジンや外部サービスとの機能連携を追加するリリースではありません。
