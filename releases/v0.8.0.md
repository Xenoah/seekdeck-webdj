# SeekDeck v0.8.0

- サンプル追加先 `dist/samples/audio/` を用意しました。初期状態は空です。
- GitHubでフォルダーに音源を追加すると、Sample catalogワークフローが一覧を生成し、既存設定のGitHub Pagesを更新します。
- アプリは一覧だけを先に取得し、選曲時に音源のサイズ・SHA-256を確認して端末内で解析・保存します。未解析表示、一覧更新、保存後のオフライン再生に対応します。
- ローカルでは `npm run samples:index` で一覧を生成できます。1ファイル50 MiB・合計512 MiB・1000曲まで。
- このフォルダーの音源は公開されます。端末内だけで使う場合はアプリの「音源を追加」を使ってください。
