# SeekDeck v0.4.0 — Mobile performance UI

- スマホ専用の下部タブ：デッキ / ミキサー / 曲 / サンプル。
- A〜Dの切り替え、再生中の表示、タッチ用の曲ロードボタン。ミキサーはA/BまたはC/Dを表示。
- 大きなトランスポート、4×2ホットキュー、タッチによるキュー削除とサンプル編集。
- 縦・横画面、セーフエリア対応。PCの自由配置とスマホの表示状態を別々に保存。
- タブを切り替えても音声処理を維持。再読込時は停止状態で復元。

Chromiumで画面幅360/390px・横画面・タッチ操作・音声継続・状態復元を確認。実機iOS/Androidやコントローラーの動作保証を追加するものではありません。

GitHub Pagesを初めて使う場合は、リポジトリの Settings → Pages → Source を GitHub Actions に設定し、GitHub Pagesワークフローを実行してください。
