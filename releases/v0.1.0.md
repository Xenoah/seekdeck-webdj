# SeekDeck v0.1.0

ブラウザ上で動く、ローカル処理の4デッキDJアプリの初回リリースです。音源やワークスペースを端末内に保存して、次回も続きから編集できます。

## 主な機能

- 4デッキ再生、波形、ホットキュー、ループ、SLIP、スクラッチ、BPM・キー推定、SYNC
- EQ、フィルター、Echo・Reverb・Flanger、クロスフェーダー、サンプラー、MASTER録音
- パネルの移動・サイズ変更・表示切替、配置プリセット、Undo・Redo
- 音源・曲情報・キュー・配置・機器割当の端末内保存、セッションJSON入出力
- MIDI Learn、14-bit CC、相対入力、HID入力レポートの手動マッピング
- rekordbox XMLの一部メタデータ入出力、オリジナルデモ4曲、初回読み込み後のオフライン起動

## 起動

`seekdeck-webdj-v0.1.0.zip` を展開し、プロジェクトのフォルダーで次を実行します。Python 3が必要です。

```sh
python -m http.server 8000 --bind 127.0.0.1 --directory dist
```

ブラウザで `http://localhost:8000` を開いてください。Windowsでは `py -3` も使用できます。HTTPSの静的ホストで使う場合は `dist/` の内容を配信します。`file://` での直接起動には対応しません。

## 初期版の制限

Rekordbox / Serato DJと同じ機能をすべて実装したものではなく、全DJコントローラーへの対応も保証しません。DVS、ステム分離、各社独自データベース、CDJ USB書出、配信サービス、機器固有の液晶・モーター制御は未実装です。

キー固定・キー変更は試験的なDSPです。解析精度、音質、出力デバイス、コーデック、MIDI/HID対応は使用環境に依存します。実ブラウザの操作、実機接続、実測遅延、長時間演奏は未検証です。

保存データは端末・ブラウザ・オリジンごとに管理されます。セッションJSONには音声を含みません。元音源とJSONを別途保管してください。旧 ORBIT DJ の保存形式は維持しています。

## 検証と配布物

- PCM再生・保存状態・MIDIなど、既存の自動テスト16件を通過
- JavaScript構文、ローカル参照、オフラインキャッシュ対象を検証
- デモ4曲を含む配布ZIPと、改変確認用の `SHA256SUMS.txt` を添付

ソースコード、検証スクリプト、デモ生成スクリプトもリポジトリに収録しています。
