# SeekDeck v0.3.0 — カラフルな波形

- 低域・中域・高域のエネルギーを反映した **RGB波形** を追加しました。低域は赤、中域は緑、高域は青で表示します。
- 帯域を青・橙・白で積み重ねる **3 BAND** と、従来の **DECK** 配色を選べます。表示モードは保存されます。
- 概要波形と拡大波形の両方に対応。デモ4曲は解析済みです。従来の音源は次にロードしたときに解析します。
- 波形解析をWorkerで小分けに実行し、全曲分のPCMを一度に複製してWorkerへ送る処理を避けました。左右が逆相のステレオ音源も波形が消えません。
- 周波数別の合成音、分割処理、逆相ステレオ、保存復元を自動テストに追加しました。リリース前にChromiumで起動・描画・再生中の音源取り込みを検証します。

rekordboxの独自波形キャッシュとの互換機能ではありません。音源からSeekDeck独自の表示データを生成します。実測遅延や実機コントローラーの検証は引き続き未実施です。
