# SeekDeck v0.7.3

- MASTER録音をIndexedDBへの逐次保存へ変更し、未保存データを8 MiB以下に制限。保存遅延・容量不足を検出して停止します。
- 保存済み録音の一覧・書き出し・中断データ回収を追加。停止時に長い録音を全てデコードしないようにしました。
- 音源付き .seekdeck バックアップを追加。SHA-256検証後に音源・曲情報・設定を同一トランザクションで復元します。
- 復元中の操作と保存キューを停止し、古いPCMキャッシュや復旧用状態が復元データを上書きする競合を防ぎます。
- 実機の長時間録音は未検証です。未終了MP4の再生や大容量Blobダウンロードにはブラウザごとの制限があります。
