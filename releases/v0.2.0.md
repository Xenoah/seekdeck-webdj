# SeekDeck v0.2.0 — GitHub Pages

- GitHub Pages配信ワークフローを追加。初回設定後はmainのアプリ更新を検証して配信します。
- サブパスでPWAを起動できるよう、アプリIDとスコープを調整しました。
- オフラインキャッシュをアプリのパスごとに分離し、他のアプリのキャッシュを保護します。
- バージョンとリリースノートの更新ごとに、テスト・ZIP検証を通過した版をリリースします。公開済みの版は上書きしません。

## 初回のPages設定

[Settings → Pages](https://github.com/Xenoah/seekdeck-webdj/settings/pages) で **Source: GitHub Actions** を選び、[GitHub Pagesワークフロー](https://github.com/Xenoah/seekdeck-webdj/actions/workflows/pages.yml) の **Run workflow** を実行してください。初回有効化には管理権限が必要です。設定前は配信用ファイルの作成までを行い、公開成功とは扱いません。

Pagesと従来のブラウザ版は保存領域が異なります。移行する場合は元音源を取り込み、セッションJSONを読み込んでください。ユーザー音源のアップロードは行いません。

既存の音声・保存・MIDIテストと、サブパス起動・キャッシュ分離を検証しています。機器対応など初期版の制限はREADMEを参照してください。
