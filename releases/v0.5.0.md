# SeekDeck v0.5.0 — Local file exchange

- **rekordbox XML**：曲情報、BPM、最初のグリッド位置、8ホットキュー、ホットループ、キュー名・色、メモリーキュー、プレイリスト。
- **Traktor NML**：曲情報、BPM、最初のグリッド位置、8ホットキュー、ホットループ、メモリーキュー、プレイリスト。ミリ秒と秒を変換。
- **M3U / M3U8・PLS**：曲順、音源パス、曲名、長さ。書き出しはUTF-8。
- **CSV**：曲情報、BPM、キー、グリッド、キュー、ループ情報。引用符、日本語、セル内改行に対応。
- **Serato .crate**：曲順とパスを読み書き。キュー・解析情報・database V2は対象外。
- 読み込みプレビュー、一致／未登録／重複／未対応パスの集計、照合結果CSV、キャンセル、曲情報の上書き選択。
- 音源フォルダー取り込みで相対パスを保持。元パス・フォルダーの一致を優先し、曖昧な同名音源は更新しない。
- 読み込んだホットループをパッドで呼び出し。プレイリストの順序と同じ曲の再登場を保存・表示・再出力。
- 曲情報と新しいクレートを一つのIndexedDBトランザクションで保存。

**検証**：33件のNodeテスト、静的参照／キャッシュ検査、Chromiumで独立したXML/NML例・6形式の往復・プレビュー取消・ファイル選択とダウンロード・ホットループ再生・保存復元を確認。

音声ファイルは交換ファイルに含まれません。元音源を先に登録し、読み込み結果を確認してください。XML/NMLには実際の絶対パス、絶対パスからSerato crateを作る場合は `_Serato_` の親フォルダーが必要です。記載のないキューは保持します。フォルダー階層はクレートに平坦化し、可変テンポは最初の位置だけを使用します。各社アプリでの実機読み込み、独自DB、CDJ USB書き出し、全バージョンとの互換は未検証です。

GitHub Pagesの初回有効化は Settings → Pages → Source: GitHub Actions が必要です。以降は更新ごとにテストして配信します。
