# SeekDeck v0.9.0 — DDJ-FLX4

DDJ-FLX4を既定プリセットにし、上面ジョグの回転方向・過大な移動と、側面の微調整が使えない問題を修正しました。

- 公式MIDI一覧に基づく147割当を追加。両デッキのPLAY/CUE/SYNC、14-bit TEMPO・フェーダー・EQ・フィルター、選曲・LOAD、ループ、ホットキュー・SHIFT削除、BEAT JUMP / BEAT LOOP / SAMPLERに対応。
- 上面はスクラッチ、側面は一時的なテンポ微調整、SHIFT＋上面は曲内検索。Vinyl OFFとSHIFT途中切替のタッチ解除も処理します。
- ジョグを `value - 64` として解釈し、回転量を音声移動距離へ積算。1 tick = 2.5 msを初期校正値に使用し、入力間隔による感度変化を抑えます。校正値はMixxx実装を参考にした値で、メーカー保証値ではありません。
- FLX4のMIDI Learnは上面・側面・タッチを一式で補完。14-bit CCはLSBを学習した場合も正規化し、新しいMSB/LSBの組を1回だけ適用します。汎用機器の片側CC更新も維持。
- FX SELECT / BEAT / LEVEL / ONとA・B・両方の割当を、SeekDeckのEcho / Reverb / Flangerへ接続。SMART CFX / SMART FADERやメーカー固有FXの再現は含みません。
- 新規セッションはFLX4、既存のカスタム割当は保持。更新前から利用している場合は **MIDI → DDJ-FLX4 → 既存MIDI割当を置き換えて適用** を一度実行してください。

検証: 自動テスト141件、静的モジュール・オフラインキャッシュ検証、Chromium統合テストが成功。疑似MIDIポートから実際のAudioWorkletへ入力し、スクラッチの移動・停止、側面テンポ復帰、LOAD、ループ、ホットキュー削除の保存、FXの音声経路を確認しました。実機FLX4での接続・操作・LED・USB遅延は未検証です。

## English

DDJ-FLX4 is now the default controller preset. This release fixes incorrect platter direction/excessive movement and adds the missing rim pitch bend.

- 147 mappings cover both decks, transport, 14-bit tempo/mixer controls, browsing and loading, loops, hot cues and shifted deletion, Beat Jump / Beat Loop / Sampler, and SeekDeck's three FX.
- Top touch performs distance-based scratching; the rim applies a small temporary pitch bend; shifted top rotation searches the track. Vinyl-off and shifted touch-release messages are handled separately.
- FLX4 MIDI Learn reconstructs the complete jog/touch mapping and recognizes 14-bit control pairs even when the LSB is received first. Existing generic controllers retain cached single-byte updates.
- Existing custom mappings are preserved. Existing users should apply the **DDJ-FLX4** preset once from the MIDI settings to replace their old mapping.
- 141 automated tests, static checks, and the complete Chromium integration suite pass, including simulated MIDI input through the real AudioWorklet, library loading, persistent cue deletion, loops, and FX routing. Physical FLX4 hardware, LEDs, USB latency, and manufacturer-specific Smart features have not been verified or reproduced.
