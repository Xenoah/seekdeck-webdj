# SeekDeck v0.5.1 — GitHub Pages root entry

GitHub Pagesを「Deploy from a branch / main / (root)」で公開すると、DJ画面の代わりにREADMEが表示される問題を修正しました。

- リポジトリ直下に `index.html` と `.nojekyll` を追加。通常のPages URLから `dist/` のDJ画面へ移動します。クエリとフラグメントも引き継ぎます。
- ブランチ公開とGitHub Actions公開を判定し、二つの配信処理が同じサイトを上書きし合わないようにしました。
- 配布ZIPにも起動用HTMLを含めました。
- ブランチ公開を再現したChromium検証で、起動・音声再生・Service Workerの範囲・オフライン再読込を確認します。
- Pagesが有効なら、実際の公開URLで新バージョンのDJ画面と音声再生を確認してからリリースします。

すでに `main / (root)` で公開している場合、Pages設定の変更は不要です。
